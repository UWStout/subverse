# SUBVerse
This is a collection of tools and scripts to help with managing a subversion repository used in a university setting for game development projects.

It is WIP and being developed with features specific to our situation. Currently, it has the following:
- `Subversion`: A Docker Compose stack for running subversion with Apache2 for web-dav access, svnserve for svn protocol access, and IF.SVNAdmin for management.
